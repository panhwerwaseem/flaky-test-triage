# Changelog

All notable changes to this skill are recorded here. Versions follow [Semantic Versioning](https://semver.org).

## 0.1.0 - 2026-11-06

### Added

- `SKILL.md` with the triage protocol: hard rules and an eight-step workflow.
- `scripts/repro.py` with measure and verify modes, parallel runs, and per-run random seeds.
- `scripts/classify.py` for cause-bucket hints from failure logs.
- References for root causes and for test-runner flags.
- Three seeded flaky fixtures with eval cases, and trigger queries.
- Unit tests, a format validator, and a CI workflow.
